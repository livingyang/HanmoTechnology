# 汉末 IP · 子龙哥哥 Mascot 设计 Brief

> 版本 v1.0 · 2026-10-19
> 定位：汉末科技（OPC 一人公司）主品牌形象。真人动漫头像萌化派生，角色即本人。
> 参考图：`ip/mascot-concept-v1.png`

---

## 1. 定位决策

| 项 | 结论 | 说明 |
|---|---|---|
| 公司形态 | OPC（一人公司） | 公司品牌 = 个人品牌，无需拆分 |
| 身份模型 | 真人萌化为主品牌脸 | 动漫头像本身已是插画资产，可注册、可授权 |
| 角色性质 | 「汉末世界的子龙哥哥」 | 既是开发者化身，又是世界观内角色，可进游戏客串 |
| 调性 | 亲和萌系 | 补硬核产品（Sekiro / 战棋）的冷暖平衡 |

**战略逻辑**：主 IP 用真人萌化吃「露脸开发者」的信任红利；虚构「子龙武将」作为可选宇宙形象，等 P4 再叠加，不急于此时拆两套。

---

## 2. 外形规格

| 维度 | 规格 |
|---|---|
| 头身比 | 2–2.5 头身 chibi（倾向更 Q：大头、短肢、小身体） |
| 发型 | 棕色分层长发，带柔和刘海，长度到肩（保留原头像特征） |
| 瞳色 | 深棕 / 琥珀 |
| 服装 | 素白／浅银札甲，内搭深色高领，肩部朱红披风 |
| 武器 | 银龙枪 + 红色枪缨（**保留，必带**） |
| 表情 | 呆萌、自信、亲和，略带少年气 |
| 画风 | 平涂赛璐珞 + 干净线稿，避免写实渲染 |

---

## 3. 配色规范（hex 参考值）

| 用途 | 色值 | 备注 |
|---|---|---|
| 主铠甲 | `#D9D6CE` / `#CFCBC2` | 素白偏银，暗部灰 |
| 披风 / 枪缨 | `#B02A26`（暗部 `#8A1F1C`） | 汉红，品牌主色 |
| 头发 | `#3B2A1E`（高光 `#6B4A32`） | 深棕分层 |
| 肤色 | `#F5D5BE`（暗部 `#E6B79C`） | 暖肤 |
| 背景暖米 | `#F4EAD8` | 概念稿底色 |
| 紫色点缀 | `#8E6FA8` | 承接原头像紫调，仅作 accent |

**主色原则**：素白 + 银 + 朱红为三角主色；紫色仅作记忆锚点，不做大面积。

## 4. 表情 / 姿势库（后续衍生）

**表情**：呆萌默认 / 自信笑 / 惊讶 / 比心 / 躺平 / 鞠躬

**姿势**：站立持枪 / 收枪比耶 / 抱臂 / 奔走 / 打坐

**用途映射**：

| 场景 | 用法 |
|---|---|
| Steam 开发者头像 / 社区 | 头像裁切（头部特写） |
| Steam 商店页 capsule | 半身 + 品牌字 |
| 官网 favicon | 极简头形符号（从角色提炼） |
| devlog / 视频 | 表情包化出镜 |
| 游戏内客串 | 彩蛋 NPC（P4 可选） |

---

## 5. 禁区（合规 / 品牌）

- ❌ 不用写实照片脸，只用插画/CG 化形象
- ❌ 不穿现代服装，保持汉末武将世界内一致性
- ❌ 不儿童化、不性化，成年角色萌化不等于幼态化
- ❌ 不影射现实政治，纯冷兵器乱世美学
- ❌ 造型避开《真三国无双》《三国杀》等既有 IP 的辨识特征（避免侵权）

---

## 6. 商标与资产

- 「汉末」为历史词，文字不可独占；**角色造型 + Logo 设计**可作为美术作品申请注册。
- 当前 `mascot-concept-v1.png` 为 AI 生成概念稿，**需经过人工二次绘制/精修**后才能作为正式商标图样提交。
- 建议在 P2 定稿后，出一版矢量稿（AI/SVG）用于印刷与 favicon 缩放。
