# 2026-10-19 · 汉末 IP 形象启动

## 背景
子龙哥哥提出为公司「汉末」设计 IP，询问是否合理及如何推进。

## 结论 / 决策
- 合理，且当前正是时机（Steam 上线期，统一品牌识别）。
- IP 三层结构：品牌图腾 / IP 角色 / 世界观。
- 角色调性选定：**Q版（亲和萌系）**，即「子龙哥哥」真人动漫头像萌化派生。
- 公司为 OPC（一人公司）→ 公司品牌 = 个人品牌，真人萌化当主品牌脸成立；虚构「子龙武将」作为可选宇宙形象，P4 再叠加。
- 头像原图偏写实绘（棕发、紫底、深色高领），适合作为 img2img 基底。
