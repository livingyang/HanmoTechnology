### 教训

- 多 AI 协作时，commit message 应**自己核对每个声明是否真的改了**：
   ab05617 message 写"汉墨→汉末 标题/标签/缩略图/manifest"——
   实际只改了 manifest.json + thumbnail.svg + docs/index.html，
   **products.json 没改**。AI 应在 commit 前对 message 各项做一次
   git diff 校验。
- bash here-doc 与复合命令（`&&` 链）混用时容易 EOF 误截断——本轮第一次
  commit 失败就是这个原因。**最佳实践**：here-doc 单独写临时文件，
  git commit -F tmpfile 分开跑，不放在 `cat > tmp <<EOF && git commit`
  这种一行里。详见 ~/.workbuddy/skills/git-multiline-commit/。
