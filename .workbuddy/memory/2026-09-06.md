### 教训 (b68d550)

**用 Write 工具创建的 tmp 文件若放在仓库根 + `git add -A`，会被一起 add 进去**：
- Write 写到 `.git-commit-msg.tmp` (仓库根)
- `git add -A` 把 tmp 也加了 → 误吞
- `git commit -F .git-commit-msg.tmp` 同时把 tmp 当 message 读，
  并把它作为新文件 snapshot
- `rm -f` 后 git status 显示 `deleted: .tmp` —— 文件已经在 commit 里"出生+死亡"
- 必须 follow-up commit 删掉 (`b68d550`)

**正确做法**：tmp 写到 `.git/hmw-msg-<PID>.txt`，`.git/` 下任何改动都不会被
`git add` 跟踪，从根上避免误吞。已更新到 git-multiline-commit skill。
